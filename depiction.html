插件介绍

CPU 智能温控 —— 为越狱 iPhone 打造的智能温控管理插件。

注入温控守护进程，接管 CPU/GPU 频率与功率策略，让你在省电与性能之间自由切换。

功能亮点

  • 三种常驻模式：智能 / 低功耗 / 性能模式，一键切换
  • 游戏强制满频：识别为游戏的 App 全程满频，其它 App 照常省电
  • App 档位：每个应用可单独钉「满频 / 低频率 / 原生 / 自动」
  • 状态浮窗：频率 · 模式 · 深度/提速，另可显示 电量 / 温度 / 帧率 / CPU / 内存 / 时间 / 下载 / 上传；字号 6~20、可隐藏背景、长按锁定、位置微调
  • 无操作深度省电 + 视频场景优化
  • 一键自检：30 秒体检，给出频率/温度报告
  • 定时切档：按星期与时段自动切换档位
  • 充电管家：充电上限（到点停充）+ 实时显示
  • 温控保护：防暗屏 / 高温警告 / 过热保护
  • 高刷解锁：持续 120，丝滑流畅
  • 后台管控：禁后台刷新 / 后台网络 / 自动启动，伪装低电量模式，省电模式不自动锁屏，电池保持原色，禁用内存压力
  • 低功耗增强：桌面原生频率

    • 安装前建议先卸载旧的「CPU 智能温控」；本包已内置自动替换。
